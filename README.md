# bex-co/homebrew-tap

Homebrew tap for [Bex](https://github.com/bex-co/bex) tools.

```bash
brew install bex-co/tap/bex
```

`Formula/bex.rb` is generated and pushed automatically by the
[`release (bex CLI)` workflow](https://github.com/bex-co/bex/blob/main/.github/workflows/cli-release.yml)
on every `bex-cli/v*` release — do not edit it by hand.
